# 数据目录定位

在开始会话或用户更改目录时读取本文件；本会话已确定位置后直接复用。

Skill 目录的 `data-location.json` 保存 `version`、`source`、`path`。记录中的相对路径按 skill 目录解析，默认是 `../data`。按以下优先级选择位置：

1. 用户本次指定的目录；相对路径按当前工作目录解析。
2. 先前记录且仍可用的用户指定目录。
3. 为本 skill 指定目录的 `AGENTS.md`：先选当前工作目录向上最近的一份，找不到再选 skill 目录向上最近的一份；相对路径按该文件所在目录解析。
4. 先前记录且仍可用的其他目录；否则使用默认目录。

路径或来源变化时才写回定位文件，来源使用 `user`、`agents` 或 `default`；后续会话直接复用，不重复询问。默认路径保持相对形式，其他位置记录解析后的路径。更改位置时迁移已有资料与进度，确认新目录可读后再停止使用旧目录。Skill 目录不可写时，仍可读取已有定位记录或复用 `AGENTS.md` 中持久指定的路径；只有新选路径无法持久记录时，才说明并请求可保存配置的位置。
